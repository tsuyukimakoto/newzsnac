## Purpose

ローカルで起動した Newzsnac の常駐プロセス群を明示的かつ安全に停止し、残留プロセスによる次回起動時の競合を防ぐ。

## ADDED Requirements

### Requirement: mise から実行中のサービス群を停止できる
システムは `mise run start` で起動したスーパーバイザーと、その配下の Web、収集、分析プロセスを `mise run stop` によって正常終了できなければならない（SHALL）。

#### Scenario: 実行中の Newzsnac を停止する
- **WHEN** 利用者が別ターミナルから `mise run stop` を実行する
- **THEN** システムは記録された Newzsnac スーパーバイザーへ正常終了を要求する
- **AND** スーパーバイザーは配下の全サービスを停止する
- **AND** 停止コマンドは停止完了を示して成功する

#### Scenario: すでに停止している
- **WHEN** Newzsnac が実行されていない状態で利用者が `mise run stop` を実行する
- **THEN** 停止コマンドは停止済みであることを示して成功する

### Requirement: 停止対象を実行記録によって限定する
停止コマンドは、Newzsnac が起動時に専用の実行記録へ保存したスーパーバイザー PID だけを停止対象にしなければならない（MUST）。ポート番号または一般的なプロセス名に一致するプロセスを一括終了してはならない（MUST NOT）。

#### Scenario: 別のプロセスが既定ポートを使用している
- **WHEN** Newzsnac の有効な実行記録がなく、別のプロセスが既定ポートを使用している状態で停止コマンドを実行する
- **THEN** 停止コマンドは別のプロセスへシグナルを送らない
- **AND** Newzsnac は停止済みであることを示して成功する

#### Scenario: 古い実行記録が残っている
- **WHEN** 記録された PID のプロセスが存在しない状態で停止コマンドを実行する
- **THEN** システムは古い実行記録を削除する
- **AND** Newzsnac は停止済みであることを示して成功する

### Requirement: 実行記録の保存先を設定できる
システムは実行記録ファイルの既定パスをコード上の設定値として提供し、`.env` または環境変数による上書きを許可しなければならない（SHALL）。

#### Scenario: 既定の保存先を使用する
- **WHEN** 実行記録パスが設定されていない
- **THEN** 起動コマンドと停止コマンドは同じ既定パスを使用する

#### Scenario: 保存先を上書きする
- **WHEN** `.env` または環境変数で実行記録パスが設定されている
- **THEN** 起動コマンドと停止コマンドは指定されたパスを使用する
