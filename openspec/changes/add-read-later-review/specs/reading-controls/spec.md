## ADDED Requirements

### Requirement: あとで読むをキーボードで処理する
システムは、入力欄以外にフォーカスがあるとき、通常Indexの `b` で現在の記事を「あとで読む」へ追加して既読にし、次の記事へ進まなければならない（SHALL）。「あとで読む」Indexでは `j` で現在の記事を一覧から除外して次へ進み、`k` では除外せず前の記事へ戻らなければならない（SHALL）。既存の `o` は、どのIndexでも現在の記事の正規URLをアクティブな新規タブで開く操作として維持しなければならない（MUST）。

#### Scenario: 通常Indexであとで読むへ送る
- **WHEN** 入力欄以外にフォーカスがある状態で利用者が `b` を押す
- **THEN** システムは現在の記事を「あとで読む」と既読に記録し、次の記事を選択する

#### Scenario: あとで読むIndexを次へ進む
- **WHEN** 入力欄以外にフォーカスがある状態で利用者が「あとで読む」Indexの記事に対して `j` を押す
- **THEN** システムは現在の記事を「あとで読む」から除外し、次の記事を選択する

#### Scenario: あとで読むIndexを前へ戻る
- **WHEN** 入力欄以外にフォーカスがある状態で利用者が「あとで読む」Indexの記事に対して `k` を押す
- **THEN** システムは現在の記事を「あとで読む」に残し、前の記事を選択する

#### Scenario: 原文を直接開く
- **WHEN** 入力欄以外にフォーカスがある状態で利用者が `o` を押す
- **THEN** システムは現在の記事の正規URLをアクティブな新規タブで開き、Newzsnacの読書位置を維持する

#### Scenario: 入力中はあとで読むショートカットを抑止する
- **WHEN** 入力欄にフォーカスがある状態で利用者が `b` を入力する
- **THEN** システムは記事状態を変更せず、文字入力として処理する
